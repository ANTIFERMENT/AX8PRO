# AX 8 PRO v1.5.2 (20)

## Настройки

- «Подключение и мониторинг» разделены на два независимых раскрываемых раздела: «Подключение» и «Мониторинг».
- «Оформление» переименовано в «Персонализация».
- В разделе «Обновления» удалена визуальная строка «Источник»; проверка происхождения и подписи APK внутри OTA не отключена.
- Убраны названия сторонних платформ из сообщений об ошибке обновления и старое название фонового уведомления.

## Частота обновлений

- Новый отдельный режим «Автоматически» по умолчанию.
- Ручной ползунок от 0,5 до 5 секунд с шагом 0,1 с; ручное значение 0,1 с удалено.
- Автоматическая частота адаптируется по измеренному времени полного цикла опроса. Минимум 0,5 с, максимум 5 с; при сетевых ошибках применяется постепенный откат к более редкому опросу.
- Единое поведение в открытом приложении и в пользовательском фоновом режиме. Сначала ждём завершения предыдущего цикла, затем выполняем новый.
- На экране показывается текущий адаптивный интервал без пересоздания экрана и сброса прокрутки.
- Автоматическая частота определяется измерениями ответов конкретного AX8, а не несуществующим API максимальной скорости обновления.

## Проверка

- Синтаксический анализ 17 Java-файлов пройден локально.
- 7 групп unit-тестов адаптивной частоты пройдены на Java 17.
- Полная Android-сборка и публикация релиза требуют отдельного подтверждения в GitHub Actions.
