# AX8 PRO CONTROL v1.5.3 (21)

## Мониторинг
- Значение автоматического интервала теперь всегда отображается справа от кнопки «Автоматически», обновляется без пересоздания экрана.
- Ползунок ручного выбора 0,5–5,0 с всегда остаётся видимым. При движении ползунка включается ручной режим.

## Запуск и показания роутера
- При старте восстанавливается последний локальный снимок LTE-параметров.
- Начальная информация о состоянии сети выводится сразу после ответа WebUI, до получения списков клиентов, SMS и блокировок.
- Старый снимок отмечается состоянием обновления, а не показывается как подтверждённое онлайн-состояние.
- Скорость первого фактического получения данных всё ещё зависит от ответа роутера и текущей сети.

## Батарея
- Добавлен индикатор ⚡ при подтверждённой зарядке и цветовое выделение значения.
- Добавлена поддержка альтернативного поля процента батареи.

## OTA
- Проверка обновлений при запуске теперь действительно вызывается, если включена соответствующая настройка.
- Окно проверки, предложения новой версии и загрузки заменено единым анимированным интерфейсом в цветах текущей темы.
- Предложение обновления больше не выводит технический текст из удалённого описания релиза.
- Загрузка отображает число переданных байт, долю и индикатор.
- Для установки используется Android ACTION_INSTALL_PACKAGE с временным разрешением чтения APK.
- После успешной замены APK добавлено уведомление с явным действием «Открыть приложение». Саму системную кнопку «Открыть» Android приложение не контролирует.

## Название
- Подпись приложения в лаунчере: **AX8 PRO CONTROL**.
- Package name и постоянная подпись для OTA остались прежними.

## Проверка
- Исходные файлы и изменения перечитаны из GitHub.
- Полная APK-сборка и поведение штатного установщика на пользовательском устройстве требуют отдельного подтверждения.
