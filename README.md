# AX 8 PRO

Android control center for OLAX AX8 Pro with official OTA updates.

The source ZIP `AX8PRO_SOURCE.zip` can be uploaded to the repository root. GitHub Actions imports the Gradle project, builds and signs `AX8PRO.apk` using the secret `AX8PRO_SIGNING_BUNDLE`, and publishes an official `update.json`.

**Status:** OTA bootstrap. The Android project and permanent signing secret must be added before the first release.

Official update channel: https://github.com/ANTIFERMENT/AX8PRO/releases/latest/download/update.json
