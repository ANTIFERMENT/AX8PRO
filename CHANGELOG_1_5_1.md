# AX 8 PRO v1.5.1 (19)

## Интерфейс и настройки

- Все настройки представлены шестью раскрывающимися категориями с аккуратными заголовками, вторичным текстом и плавной анимацией раскрытия.
- Настройка частоты обновления теперь реализована одним ползунком от 0,1 до 5,0 секунды с шагом 0,1 секунды. Слева максимальная доступная частота последовательного опроса AX8; значение по умолчанию 0,1 с.
- Цвет акцента выбирается из готовой палитры. Дополнительный ручной RGB-редактор акцента не используется.
- Убраны названия сторонних проектов и платформ из пользовательских строк интерфейса.
- Изменение параметров не прокручивает настройки к началу, раскрытые категории сохраняются в пределах текущего сеанса.
- Повторное касание текущей нижней вкладки не запускает переход или новый экран. Анимация при смене вкладки сохранена.

## Хозяин и управление

- Автовыбор хозяина включён по умолчанию: активный Wi-Fi IP телефона сопоставляется с текущим списком клиентов AX8.
- Несовпадающий устаревший MAC WebUI не заменяет однозначное совпадение по Wi-Fi IP телефона.
- Из ручного списка управляющих устройств скрыты записи без актуального IPv4.
- Защита от массового QoS и случайной блокировки управляющего устройства сохранена.

## Сборка и OTA

- versionName: 1.5.1; versionCode: 19.
- packageName: ru.xarkon.ax8pro.
- GitHub Actions должен подписать AX8PRO.apk постоянной подписью и опубликовать update.json в официальном канале при успешном завершении сборки.
- Фактическая Android-сборка и тест на роутере требуют подтверждения.
